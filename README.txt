Sourwaters Music — GitHub Pages, без локального сервера

Док-панель OBS:
https://sourwaters.github.io/sourmusic-embed-test/

Оверлей OBS, источник «Браузер», 550 × 140:
https://sourwaters.github.io/sourmusic-embed-test/music_overlay.html

Один раз в Streamer.bot:
1. Actions → Add: имя SourMusic State, Enabled включено.
2. Sub-Actions → Add → Core → C# → Execute C# Code.
3. Замените код содержимым SourMusic-State.cs, нажмите Compile,
   затем Save and Compile. Триггер не нужен.
4. Держите Streamer.bot запущенным, WebSocket включённым.
   Плеер проверяет 8080, затем 8181. Защиту паролем отключать не надо:
   если она включена, страница запросит пароль, не сохраняя его на сервере.

В плеере добавьте ссылку и ник. Заказы зрителей принимаются через награду
Twitch «Заказать музыку» с обязательным текстовым вводом ссылки.

Держите открытым только один плеер. Оверлеев может быть несколько.
Пауза, окончание и ошибка скрывают карточку. Если плеер закрыт, карточка
исчезнет примерно через 10 секунд. После перезагрузки очередь сбрасывается.

Ничего из ZIP запускать не нужно: это резервная копия исходников.
Код действия и инструкция также находятся внизу страницы плеера.
Действие передаёт состояние через временную переменную Streamer.bot;
очередь, ник и данные о текущем треке не загружаются на GitHub.

Проверено автоматическими тестами: выбор портов, подписка, события,
чтение состояния, Unicode, очистка и устаревание карточки.
Действие в вашей копии Streamer.bot и работа в OBS требуют проверки
после однократной настройки.
